# Telehealth MVP - Mobile Application

A full-featured telehealth application built with Expo (React Native), TypeScript, and Xano backend. This application enables patients to connect with doctors for remote consultations with integrated payment processing via Paystack.

## 🚀 Technology Stack

### Frontend
- **Expo SDK 54+** - Cross-platform mobile development
- **React Native 0.81** - Mobile UI framework
- **TypeScript** - Type-safe development
- **Expo Router** - File-based navigation
- **NativeWind** - Tailwind CSS for React Native
- **React Query** - Server state management
- **Zustand** - Client state management
- **Axios** - HTTP client

### Backend
- **Xano** - No-code backend platform
- **PostgreSQL** - Database (via Xano)
- **REST API** - Auto-generated by Xano

### Payment & Video
- **Paystack** - Payment processing
- **Stream Video SDK** - Video consultations (ready to integrate)

## 🛠️ Setup Instructions

### Prerequisites
- Node.js 18+ installed
- npm or yarn
- Expo Go app on your mobile device (for testing)
- Xano account (for backend)
- Paystack account (for payments)

### 1. Install Dependencies

```bash
npm install
```

### 2. Configure Environment Variables

Copy `.env.example` to `.env` and fill in your credentials:

```bash
cp .env.example .env
```

Update the following in `.env`:

```env
# Xano API Configuration
EXPO_PUBLIC_XANO_API_URL=https://your-instance.xano.io/api:your-api-group
EXPO_PUBLIC_XANO_API_KEY=your-api-key

# Paystack Configuration
EXPO_PUBLIC_PAYSTACK_PUBLIC_KEY=pk_test_your_public_key

# Stream Video Configuration (optional)
EXPO_PUBLIC_STREAM_API_KEY=your-stream-api-key

# App Configuration
EXPO_PUBLIC_APP_ENV=development
```

### 3. Set Up Xano Backend

1. Create a Xano account at [xano.com](https://xano.com)
2. Create a new workspace
3. Import the database schema (see Database Schema section)
4. Create API endpoints as documented
5. Copy your API URL and Key to `.env`

### 4. Run the Application

```bash
# Start the development server
npm start

# Run on iOS simulator
npm run ios

# Run on Android emulator
npm run android

# Run on web
npm run web
```

### 5. Test with Expo Go

1. Install Expo Go on your mobile device
2. Scan the QR code shown in the terminal
3. The app will load on your device

## 🗄️ Database Schema (Xano)

### Tables to Create in Xano:

1. **users** - User accounts
2. **doctor_profiles** - Doctor information
3. **patient_profiles** - Patient medical information
4. **appointments** - Consultation bookings
5. **availability** - Doctor availability schedule
6. **messages** - Chat messages
7. **medical_documents** - Patient documents
8. **payments** - Payment records

See the MVP requirements document for complete schema details.

## 🔐 API Endpoints Required

### Authentication
- `POST /auth/signup` - User registration
- `POST /auth/login` - User login
- `POST /auth/logout` - User logout
- `POST /auth/forgot-password` - Password reset request
- `GET /auth/me` - Get current user

### Doctors
- `GET /doctors` - List doctors (with filters)
- `GET /doctors/:id` - Get doctor details
- `GET /doctors/:id/availability` - Get availability

### Appointments
- `POST /appointments` - Create appointment
- `GET /appointments` - List user appointments
- `GET /appointments/:id` - Get appointment details
- `PUT /appointments/:id` - Update appointment
- `DELETE /appointments/:id` - Cancel appointment

### Payments
- `POST /payments/initialize` - Initialize Paystack payment
- `POST /payments/verify` - Verify payment
- `GET /payments/history` - Payment history

### Messages
- `POST /messages` - Send message
- `GET /messages/conversation/:userId` - Get conversation
- `GET /messages/conversations` - List conversations

## 💳 Paystack Integration

The payment flow is designed but requires Paystack WebView integration:

1. Install Paystack package:
```bash
npm install react-native-paystack-webview
```

2. Update `app/booking/payment.tsx` to integrate Paystack WebView
3. Implement payment verification on Xano backend
4. Set up Paystack webhooks for payment confirmation

## 📹 Video Consultation Setup

To enable video consultations:

1. Create a Stream Video account at [getstream.io](https://getstream.io)
2. Install Stream Video SDK:
```bash
npm install @stream-io/video-react-native-sdk
```

3. Create Xano endpoint to generate Stream user tokens
4. Implement video call screen in `app/consultation/[id].tsx`
